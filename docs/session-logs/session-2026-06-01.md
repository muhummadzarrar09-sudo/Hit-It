## Decisions Made

1. **No seed data ever again.** App starts completely blank. Zero demo content.
2. **GSAP over CSS transitions.** All animations are timeline-based, cancellable, and 60fps.
3. **Tailwind v4 CSS-native.** Dropped JS config. All tokens in `@theme` block.
4. **No cmdk library.** Custom-built command palette with fuzzy search.
5. **No Radix UI.** All UI primitives are custom (lighter bundle, full control).
6. **Tauri over Electron.** Rust wrapper = smaller binary, better security, native feel.
7. **Paddle over Stripe.** Merchant of record, supports Pakistan, handles tax.
